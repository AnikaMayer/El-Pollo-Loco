Class: World

World(_canvas, _keyboard)

Represents the game world and acts as the central controller. Manages the game loop, all game objects, collisions, item collection, HUD rendering and game end logic.

new World(_canvas, _keyboard)

Creates a new World, sets up the canvas context, starts the draw loop and registers all game intervals.
