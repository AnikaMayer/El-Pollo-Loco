Class: Keyboard

Keyboard()

Tracks the current input state for both keyboard and touch controls. Keyboard keys are updated in game.js via keydown/keyup listeners. Touch buttons are registered directly in this class.

Creates a new Keyboard instance and registers all touch controls.
